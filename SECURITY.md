# Security Policy

## Um SaaS Open Source Feito com a Comunidade

Este projeto tem a visão de ser um SaaS White-label totalmente Open Source. Convidamos e encorajamos a comunidade de desenvolvedores, engenheiros de infraestrutura e especialistas em segurança a auditar nosso código (Frontend, Backend Java, Painel Admin e scripts IaC) e nos ajudar a manter a plataforma segura para todos.

## Supported Versions

Garantimos atualizações de segurança para as versões estáveis mais recentes.

| Versão  | Suportado          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Para proteger as pessoas e empresas que já fazem self-hosting dessa solução em seus próprios ambientes, **por favor, não relate vulnerabilidades de segurança através de issues públicas no GitHub.**

Se você descobrir uma vulnerabilidade ou tiver uma sugestão de melhoria de segurança, envie um e-mail diretamente para **[SEU_EMAIL_AQUI]**.

### O que esperar:
* **Resposta inicial:** Você receberá uma confirmação de recebimento em até 48 horas.
* **Trabalho em Conjunto:** Nós adoramos colaboração. Se desejar, podemos trabalhar juntos no desenvolvimento do patch de correção.
* **Reconhecimento:** Assim que a falha for validada e corrigida, você receberá os devidos créditos nas notas de lançamento (Release Notes) como contribuidor de segurança.
